## §15.231 6 SKU 漂移深挖：DECIMAL(12,3) 量化 + 严格不等式

### 一、现象

caliber_probe matrix 判据③ FAIL：n=9999，max=**0.3357**，6 行 >0.05。
6 个 SKU 全是 jd / `__C__` 维 / barcode='' 合计行：

| SKU | fused 差 |
|---|---|
| SKU-03314-J | 0.0976 |
| SKU-03530-J | 0.1189 |
| SKU-04010-J | **0.3357**（最大） |
| SKU-04114-J | 0.2964 |
| SKU-06610-J | 0.2645 |
| SKU-08535-J | 0.2775 |

### 二、根因链（精度/量化问题）

1. 物化 ds 列是 DECIMAL(12,3)，重建时四舍五入到 3 位；直算用全精度浮点。
2. 这 6 个 SKU 的比值**恰好落在趋势阈值上**：1.15（03314、03530、04010、06610）
   或 0.85（04114、08535）。
3. `rolling_predict`（`biz/sales.py:252`）用**严格不等式**
   （`s7 > s14*1.15`，`s7 < s14*0.85`）——恰好等于判"平"。
4. 舍入把比值推过线 → 等级翻 → 权重变 → fused 差 0.10–0.34。
5. 佐证：55 个 SKU 在阈值 ±0.002 内，**只有 6 个恰好在阈值上的翻了**。

数据与业务逻辑均排除：两边同一条链、同一参数；ds 值到 3 位一致。

### 三、业务影响：零

| 项 | 值 |
|---|---|
| 安全线差 | 1–6 |
| 现货 + 在途 | 1,251–5,430 |
| 告警判定翻转 | 0 |

所有消费方读物化表，用同一套舍入口径；即使降级路径触发，6 个 SKU 的
安全线差也翻不动任何告警判定。只探针判据失败。

### 四、修复选项（用户选 #3）

1. 调探针；2. `rolling_predict` 阈值比较加 epsilon；
3. **提精度到 DECIMAL(12,6)**（最彻底，改 schema + 迁移 + 全量重建）；
4. 接受为已知限制。优先级 LOW。用户选 #3 → §15.235。
