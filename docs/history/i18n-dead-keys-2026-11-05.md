## 三、脚本改了什么

1. **动态前缀登记为命名空间**：`col./fld./seg.` 不逐条判死，改由 `scan_dynamic_prefix_health()`
   盯产键函数本身（`t('col.' + ...)` 拼接是否还在、文件是否存在）。
   反证：`mv colLabels.ts` → 自检立刻红。
2. **通用键识别**：键字段（`l:` / `label:` / `name_key:` …）、元组元素 `['x', 'p.lit']`、
   对象简写 `lit: 'rf.vars.lit'`、后端 `"name_key": "task.win"`。
3. **字面量兜底**：键以完整字面量出现在任何源文件（含注释）即算未死。
4. **缺键检查改回只认 `t('字面量')`**：否则 `v: 'flow.date'`（后端字段名）会被报成 43 条假缺失。
