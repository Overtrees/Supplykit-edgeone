# decisions（ADR）：定案单独立案

本目录是定案的决策记录（ADR）：**定什么、为什么定、否掉了什么、怎么验证**。
history 只记过程（做了什么、实测多少），定案的“为什么”只写 history 是不够的——
过程会淹没理由，后人翻不到否决项。

机制未废弃，只是 2026-11-05 至 11-17 间 12 天无新文件：0002（2026-11-04）之后，
定案都只写了 history。本次 0003、0004 恢复使用。

此后够格写 ADR 的定案（定了什么、为什么定、否掉了什么）应单独立案，不只留 history。
够格的标准：改了口径、改了调度/部署结构、否掉过有分量的备选方案、或后人可能
想“为什么不那么做”的决定。编号顺序递增，文件名 `<编号>-<短名>.md`，体例沿用
0001/0002：决策 / 背景 / 被否掉的方案 / 验证 / 代价与已知限制。
